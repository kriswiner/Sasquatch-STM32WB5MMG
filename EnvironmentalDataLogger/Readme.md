
The Sasquatch Daughter Board is intended to reproduce but update the [Rodan](https://github.com/kriswiner/Rodan) Environmental Data logger concept. Both use the STM32WB5MMG module as BLE-enabled host MCU. Both make use of the APDS9253 RGB iR ambient light sensor, the HDC2010 humidity and temperature sensor, and LPS22DF barometer.
