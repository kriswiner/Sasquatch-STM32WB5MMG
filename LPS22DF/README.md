# LPS22DF Basic Robust Sasquatch STM32WB5MMG

This is a basic Arduino sketch for the ST LPS22DF barometric pressure sensor controlled by the STM32WB5MMG Sasquatch development board demonstrating ultra-low power STOP-mode operation. It supports either non-blocking one-shot measurements scheduled with `TimerMillis` or continuous 1 Hz acquisition with 64x sensor averaging, LPF1 filtering, and FIFO-watermark interrupts. Startup includes an I2C scan, `WHO_AM_I` verification, reset and configuration readback, bounded error handling, and an initial fixed pressure baseline used to report relative altitude. Serial output is optional, and detailed FIFO diagnostics can be selected independently with `ENABLE_DIAGNOSTICS`.

In continuous mode the FIFO uses dynamic-stream operation with a watermark of 11 data sample sets. Each 24-bit pressure set is read in its own three-byte transaction; a repeatable anomalous first FIFO value observed on the tested hardware is discarded, and the remaining ten values are averaged. One-shot mode instead collects a 128-sample startup baseline and subsequently makes one pressure/temperature measurement per minute. Measured average current for the tested LPS22DF + Sasquatch on breadboard was approximately 7.1 uA in one-shot mode and 14.5 uA in continuous FIFO mode; these figures include the Sasquatch, sensor breakout, and board-level implementation.
